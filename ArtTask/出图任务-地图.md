# 出图任务 · 第一章地图

项目：汉末英雄传 · 刘备篇（Unity 回合制 RPG）。
风格：**Q 版高清手绘插画**（大头小身、粗描边、厚涂、暖色），**不是像素风**。

## ⚠️ 硬性规则（先读）

1. **必须用图像生成模型出图**（gpt-image / Gemini 等）。**禁止用代码（PIL、Canvas、SVG 等）画图。**
   如果当前环境调不了图像生成模型，就停下来说明情况，不要用代码画一版顶替。
2. **只交原图**：不要缩放、不要抠图、不要裁剪，后处理由程序这边来做。
3. 需要透明的素材一律用 **纯品红 `#FF00FF` 填满背景**（模型出不了真透明）。
4. 每个文件放到下表指定的路径，名字不能改。**不要动 `Assets/` 下的任何东西，也不要改代码。**
5. 按「出图顺序」做。第 1 张涿县地图是全篇的风格参考，之后每一张都要把它作为**参考图**一起喂给模型，这样色调和线条才能统一。

## 1–2. 地图整图

**必须把对应的布局图作为参考图一起喂进去**，构图要严格照着色块的位置和大小来画。程序会按布局图判定哪里能走、哪里不能走，房子画偏了，角色就会穿墙。

接在片段 A 后面：
```
a small peaceful walled village. Follow the reference layout image EXACTLY, every color block stays in place and size:
- dark green border = dense tree line enclosing the town
- red block (top left) = Liu Bei's humble cottage, thatched straw roof, mud-brick walls, door at the bottom center facing down
- blue block (left middle) = a tavern, grey tiled roof, red pillars, cloth wine banner, door at the bottom facing down
- purple block (right middle) = a two-storey inn, grey tiled roof, red paper lanterns, door at the bottom facing down
```

## 3. 前景遮挡层（P1，地图通过后再做）

用途：角色走到树冠、屋檐后面时会被挡住，这是画面有纵深感的关键。

做法：把**已经定稿的地图**作为输入，用图像编辑模式：
```
Edit this exact image. Keep ONLY the parts that should hide a character walking behind them:
tree canopies, roofs and roof eaves, peach blossom branches, the top beam of the gate, banners.
Keep those pixels exactly where they are, unchanged, not moved, not redrawn, not restyled.
Replace EVERYTHING else (ground, grass, roads, walls below the eaves, water, cliffs) with solid pure magenta #FF00FF.
```

验收：和原图叠在一起时，保留下来的部分要完全重合，不能有错位。
