# 战斗圆盘 生图提示词

战斗时垫在敌我两列人物脚下的圆形阵台，压暗的地图上面、人物下面。要低调，不能抢人物的戏。

生成后放到 `ArtSrc/battle_disc.png`，告诉 Claude 抠底并放进游戏（`Resources/Map/Art/battle_disc.png`）。

```
游戏战斗场景用的地面圆盘贴图，中国古风，手绘水彩质感，和Q版三国角色的画风一致。
画布 1536×1024，纯品红色背景（#FF00FF），圆盘以外全部是纯品红，不要阴影、不要地面、不要任何人物和文字。
内容：一块从斜上方约 60 度俯视的圆形石质阵台，透视后是横向的扁椭圆，宽约占画布宽度的 90%，高约是宽的一半，居中。
阵台表面刻着很浅的同心圆环和一圈淡淡的云纹、八卦纹，纹路只是若隐若现的浅刻痕，不要发光、不要鲜艳的符文。
颜色：低饱和的灰褐、青灰色，明暗对比很弱，整体偏暗、偏平，像旧石板被岁月磨过，边缘有一点磨损和细小裂纹。
圆盘的外沿干净利落，和品红背景之间边界清晰（方便抠图）。
风格要求：低调、不抢眼，作为背景衬托人物，细节少而柔和。
```
