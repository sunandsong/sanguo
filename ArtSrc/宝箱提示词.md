# 宝箱 生图提示词

通用宝箱，所有地图（室内木地板、泥地、草地、营寨）都用这一个。一张图出「关着」「打开」两个状态。
生成后放到 `ArtSrc/chests/chest.png`，告诉 Claude 抠底、切开、放进游戏（`Resources/Map/Art/chest.png`、`chest_open.png`）。

要点（上一版的问题）：
- **正面朝前、左右对称**，不要斜 45°。
- **颜色要跳出地面**：地图全是褐色木头和泥土，箱子不能是褐木色。用朱红漆 + 亮金包边。
- 粗黑描边、明暗对比强，缩到很小（约 60 像素）也一眼认得出是宝箱。

```
游戏地图道具设定图，中国古风，Q版三国游戏，手绘水彩质感，粗黑墨线描边，高饱和、高对比，造型简洁、轮廓清晰，缩得很小也能一眼认出。
正面平视略带俯视（能看到正面和一点点箱盖顶面），左右完全对称，不要斜角、不要透视侧面。
画布 1536×768，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无人物。
左右并排画同一个箱子的 2 个状态，各占画布一半，居中，彼此留出明显空隙、不重叠；两个箱身的大小、位置、底边高度完全一致，每个箱身占自己那一半宽度的 65%。
每个都是一个完整连通的整体，不能有单独分开的碎片。
物体上不要出现粉色或紫色。

箱子：中国古代宝箱，箱身朱红色漆面（鲜亮的中国红），箱盖是圆拱形，四角和边沿包亮金色铜皮，正面中央一个大的金色圆形锁扣（铜钱样式）。箱盖上一条金色横带。色块大、细节少，像游戏 UI 图标一样醒目。
左：箱盖合上，锁扣扣着。
右：箱盖向后掀开立起（箱盖内侧是深红色），箱内透出一团暖金色的光，看不到具体东西。
```
