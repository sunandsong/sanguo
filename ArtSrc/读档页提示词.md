# 读档页 生图提示词

首页「读档」和游戏菜单「读档」跳转的页面：顶上一块空匾（"读档"两个字游戏里写），下面三条存档记录。
要两张图：**背景**一张、**记录卡框**一张（三条记录共用，空档由游戏压灰）。图里都**不要写字**。

生成后放到 `ArtSrc/load_bg.png`、`ArtSrc/load_card.png`，告诉 Claude 接进游戏。

## 1. 背景 load_bg

```
手机竖屏游戏的读档界面背景，中国古风，手绘水彩质感，和Q版三国角色的画风一致，暖色调。
画布 1080×1920（竖版 9:16）。
内容：一间古代书房的案头俯视视角——深色木纹书案铺满整个画面，案上散放着几卷竹简、一方砚台和毛笔、一盏小油灯透出暖黄光晕，边角有几片落下的桃花瓣。
构图：
- 顶部 0%~10% 只是书案木纹，不放任何东西（留给手机状态栏和按钮）；
- 10%~20% 正中一块横向的木质牌匾，深红底、金色描边、两端有云纹，牌匾上不要任何文字（留给游戏写"读档"）；
- 22%~92% 是大片平整干净的书案桌面，只有很淡的木纹，不放任何物件（三张存档卡片会压在这里）；
- 竹简、砚台、毛笔、油灯、花瓣只放在四个角落和画面最底部 92%~100%，要小，不进入中间区域。
不要人物，不要任何文字、印章、水印、边框。
中间桌面区域颜色均匀、偏暗一点，让上面压的浅色卡片清楚。
```

## 2. 记录卡框 load_card

```
游戏读档界面用的一条存档记录卡框，中国古风，手绘水彩质感，和Q版三国角色的画风一致。
画布 1536×512（横版 3:1），纯品红色背景（#FF00FF），卡框以外全部是纯品红，不要阴影。
内容：一张横向的米黄色宣纸卡片，四角圆润，外围一圈细细的深褐色木框，木框四角有小小的铜质包角。
卡片左侧约占卡片宽度 40% 的位置，是一个横向的长方形空白画框（内衬深褐色细边，里面是纯品红色，用来放地图缩略图），画框上下左右离卡片边缘距离相等。
卡片右侧 60% 是干净的宣纸，只有极淡的纸纹，不要任何文字、图案、印章（游戏会在这里写档案名称、等级和时间）。
卡框外沿和画框内沿都干净利落，和品红之间边界清晰（方便抠图）。
颜色柔和、低饱和，细节少，作为底板衬托上面的字和图。
```
