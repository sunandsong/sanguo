# 法术特效 生图提示词

两类图：

- **动画帧**（7 张）：一张图 8 帧，两行四列，从左到右、从上到下播放。发光的特效用**纯黑底**（我按亮度抠成半透明，光晕边缘才干净）；尘土用品红底。
- **静态素材**（1 张）：石块、药葫芦、战鼓、符纸这些实物，品红底，代码里让它们飞、转、落。

生成后放到 `ArtSrc/fx/<文件名>.png`，告诉 Claude 抠底、切帧、放进游戏（`Resources/Map/Art/fx_<名字>_<帧>.png`）。

所有动画帧通用的要求（已经写进每段提示词里）：画布 1536×1024 分成 4×2 共 8 格，每格 384×512；特效在每格里的中心点和地面线位置完全一样，帧与帧之间只有特效本身在变化；不要格子线、不要编号、不要文字。

| 文件名 | 内容 | 底色 | 用在 |
|---|---|---|---|
| cast_glow | 施法聚光 | 黑 | 所有法术施法时手前，代码里按法术染色 |
| fire_arrow | 火箭飞行（循环） | 黑 | 火计 |
| fire_burst | 火焰爆炸 | 黑 | 火计命中 |
| rock_dust | 落石尘爆 | 品红 | 落石命中 |
| heal_light | 治疗光柱 | 黑 | 疗兵、鼓舞命中 |
| rally_wave | 金色冲击波 | 黑 | 鼓舞每一下鼓声 |
| hex_storm | 紫雾紫电 | 黑 | 妖术命中 |
| props（静态） | 石块、药葫芦、战鼓、符纸等 6 个 | 品红 | 各法术的实物 |

## 施法聚光（cast_glow.png）

```
游戏战斗特效序列帧，中国古风，Q版三国游戏，手绘水彩质感，和Q版三国角色的画风一致。
画布 1536×1024，纯黑色背景（#000000），无文字、无编号、无格子线、无人物。
画布分成两行四列共 8 格（每格 384×512），是同一个特效的 8 帧动画，从左到右、从上到下按时间顺序播放。
特效在每一格里的中心位置完全一样，帧与帧之间只有特效本身的形状、大小、亮度在变化，画法和配色前后一致。
特效不要碰到格子边缘，四周留出空隙。

内容：施法时手前凝聚的一团光。
第 1～3 帧：四周细小的金白色光点向中心飞聚，越聚越多；
第 4～6 帧：中心凝成一个越来越亮的金白色光球，外面一圈柔和光晕，光球周围有几道细细的旋转光丝；
第 7 帧：光球猛地一闪，变成一个十字星芒；
第 8 帧：星芒散开，只剩几颗淡淡的光点。
颜色只用金白色（游戏里会按法术染成红、绿、紫），光球最大时直径约占格子宽度的 60%。
```

## 静态素材（props.png）

```
游戏战斗特效素材设定图，中国古风，Q版三国游戏，手绘水彩质感，粗糙墨线描边，暖色调，和Q版三国角色的画风一致。
画布 1536×1024，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无人物、无手。
两行三列排版，共 6 个素材，每个居中在自己的格子里，彼此留出明显空隙、不重叠，每个都画大，占满自己格子的 75%。
每个素材都是一个完整连通的整体，穗子、雾气都连在主体上，不能有单独分开的碎片。
素材上不要出现粉色或紫色（第 6 个符纸周围的紫气除外）。

上排从左到右：
1. 大石块：一块棱角分明的灰褐色巨石，有裂纹和青苔，像从山上滚下来的。
2. 碎石块：两三块较小的灰褐色石头粘连在一起，带一点土黄色尘土。
3. 药葫芦：一个倾斜倒着的朱红色药葫芦，葫芦口流出一缕发光的淡绿色雾气，雾气连着葫芦口。

下排从左到右：
4. 草药叶：一小簇发着淡绿色微光的草药叶子，三四片叶子连在一根小枝上。
5. 战鼓：一面正面朝前的大战鼓，红漆鼓身、铜钉、蒙皮鼓面，两根鼓槌交叉在鼓前。
6. 妖术符纸：一张黄色符纸，上面画着暗红色弯曲的符咒纹路（不要写可辨认的文字），符纸周围缠着一圈紫色的妖气，妖气连着符纸。
```
