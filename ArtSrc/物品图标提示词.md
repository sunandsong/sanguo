# 物品图标 生图提示词

物品格子里的图标。一张图出两个图标（左、右各一个），生成后放到 `ArtSrc/items/sheet1.png`，告诉 Claude 抠底、切开、放进游戏（`Resources/Map/Art/item_<Id>.png`）。

## 第一张：兵书（sheet1）

左 = 《六韬》（Id: liutao），右 = 《吴子》（Id: wuzi）。

```
游戏物品图标设定图，中国古风，Q版三国游戏，手绘水彩质感，粗糙墨线描边，暖色调，做旧质感，和Q版三国角色的画风一致。
画布 1536×1024，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无手。
左右并排画 2 个图标，各占画布一半，居中，彼此留出明显空隙、不重叠，每个都画大，占满自己那一半的 80%。
每个图标都是一个完整连通的整体，绳子、穗子都连在物体上，不能有单独分开的碎片。
物体上不要出现粉色或紫色。

左：《六韬》——一卷卷起来的竹简，竹片泛黄发旧，用深褐色麻绳捆扎，绳结垂下一小段；竹简外裹一片暗青色布帛，布帛上压着一枚小小的青铜虎形镇纸。整体厚重古朴，像传了很多代的祖传兵书。
右：《吴子》——一卷半展开的竹简，展开的部分能看到一列列竖排的墨迹（只画成模糊的墨线，不要写出可辨认的文字），竹简一端挂一条暗红色丝绦，旁边斜插一支毛笔。比左边那卷略新一些、略小一些。
```

## 第二张：涿县商店（sheet2）

一张四个图标，2×2 排。左上 = 草药（Id: caoyao），右上 = 浊酒（Id: zhuojiu），左下 = 皮甲（Id: pijia），右下 = 驽马（Id: numa）。生成后放到 `ArtSrc/items/sheet2.png`。

（兵器不用出图，直接用引擎里的兵器贴图。）

```
游戏物品图标设定图，中国古风，Q版三国游戏，手绘水彩质感，粗糙墨线描边，暖色调，做旧质感，和Q版三国角色的画风一致。
画布 1024×1024，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无手。
2×2 四宫格排 4 个图标，每个占画布四分之一，居中，彼此留出明显空隙、不重叠，每个都画大，占满自己那一格的 80%。
每个图标都是一个完整连通的整体，绳子、叶子、缰绳都连在物体上，不能有单独分开的碎片。
物体上不要出现粉色或紫色。

左上：草药——一小捆新鲜的绿色草药，叶片肥厚，根部带一点泥土，用一根细草绳扎在中间，绳结处夹一片宽大的叶子。看起来便宜、常见、乡间随手可采。
右上：浊酒——一个圆肚粗陶酒坛，土黄色陶身带几道釉痕，坛口用红布蒙住、麻绳扎紧，坛颈挂一个小木瓢。朴素的乡间自酿酒。
左下：皮甲——一件摊开正面朝前的褐色牛皮甲，胸口和肩部是一片片缝起来的皮甲片，边缘有麻线缝迹和铜扣，腰间一条皮带。耐用但简陋，不是金属甲。
右下：驽马——一匹Q版的矮壮棕色马，侧身站立，鬃毛蓬乱，配一副旧皮马鞍和粗麻缰绳，神情憨厚有点懒散。整匹马完整画出，四蹄都在画面内。
```

## 第三张：头盔、鞋子、饰品（sheet3）

一排三个图标。左 = 皮盔（Id: pikui），中 = 布靴（Id: buxue），右 = 玉佩（Id: yupei）。生成后放到 `ArtSrc/items/sheet3.png`。

```
游戏物品图标设定图，中国古风，Q版三国游戏，手绘水彩质感，粗糙墨线描边，暖色调，做旧质感，和Q版三国角色的画风一致。
画布 1536×640，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无手、无人物。
横排 3 个图标，各占画布三分之一，居中，彼此留出明显空隙、不重叠，每个都画大，占满自己那一格的 80%。
每个图标都是一个完整连通的整体，带子、穗子都连在物体上，不能有单独分开的碎片。
物体上不要出现粉色或紫色。

左：皮盔——汉代士兵的褐色牛皮软盔，圆顶，由几片皮革缝合，缝线和铜钉清晰，两侧垂下护耳，系一根皮颌带。和皮甲同一套质感，简陋耐用。
中：布靴——一双黑色千层底布靴，并排斜放，靴筒到小腿，靴口一圈深蓝布边，鞋底白色千层纳线，鞋面有一点尘土。
右：玉佩——一枚圆形青白玉璧形佩，中间有孔，表面刻浅浅的云纹，上端系一条暗红色丝绳打成如意结，下端垂一束暗红丝穗。温润有光泽。
```

## 第四张：结算面板图标（sheet4）

左 = 经验（Id: icon_exp），右 = 金钱（Id: icon_gold）。生成后放到 `ArtSrc/items/sheet4.png`，切好放到 `Resources/Map/Art/icon_exp.png`、`icon_gold.png`。

```
游戏界面图标设定图，中国古风，Q版三国游戏，手绘水彩质感，粗糙墨线描边，暖色调，和Q版三国角色的画风一致。
画布 1536×1024，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无手。
左右并排画 2 个图标，各占画布一半，居中，彼此留出明显空隙、不重叠，每个都画大，占满自己那一半的 75%。
每个图标都是一个完整连通的整体，不能有单独分开的碎片。
物体上不要出现粉色或紫色。

左：经验——一卷展开一半的竹简，竹简上方悬着一颗发着淡蓝白光的星芒（像领悟的灵光），竹简和星芒连在一起（星芒的光晕碰到竹简）。整体偏蓝白色调，干净醒目。
右：金钱——一串用红绳穿起来的金黄色方孔铜钱（五六枚叠着），旁边斜靠一锭小金元宝，铜钱和元宝挨在一起。整体金黄色，亮闪闪。
```
