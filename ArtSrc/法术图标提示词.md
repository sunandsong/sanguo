# 法术图标 生图提示词

人物页「法术」列表左边的图标。一张图出 4 个，生成后放到 `ArtSrc/tactics/sheet1.png`，告诉 Claude 抠底、切开、放进游戏（`Resources/Map/Art/tactic_<Id>.png`）。

## 第一张（sheet1）

从左到右：火计（huoji）、疗兵（liaobing）、落石（luoshi）、鼓舞（guwu）。

```
游戏技能图标设定图，中国古风，Q版三国游戏，手绘水彩质感，粗糙墨线描边，暖色调，做旧质感，和Q版三国角色的画风一致。
画布 1536×1024，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无人物、无手。
一行从左到右并排画 4 个图标，每个都在一块圆形的做旧铜质徽章底座上（4 个底座大小、样式完全一样，边缘一圈简单的回纹），每个图标宽约 330 像素，上下居中，彼此留出明显空隙、不重叠。
每个图标都是一个完整连通的整体，火焰、碎石、光点都画在徽章圆形里面，不能有飘到外面的碎片。
图标上不要出现粉色或紫色。

从左到右：
1. 火计：徽章里一支燃烧的火箭斜插着，箭杆缠着油布，橙红色火焰向上卷起，火星点点。
2. 疗兵：徽章里一个打开的小药葫芦，葫芦口飘出一缕淡绿色的气，旁边几片草药叶子，整体清新柔和。
3. 落石：徽章里几块棱角分明的大石头从上往下砸落，带着一点土黄色烟尘，石头有裂纹。
4. 鼓舞：徽章里一面立着的战鼓，红漆鼓身、蒙皮鼓面，两根鼓槌交叉在鼓前，鼓面上有一圈金色的震动波纹。
```

## 第二张起：吞食天地结构补齐的法术（2026-11-03）

还是一张 4 个、同一段风格开头（抄第一张前 6 行，只换最后「从左到右」那 4 条）。生成后放 `ArtSrc/tactics/sheet<N>.png`，切好放 `Resources/Map/Art/tactic_<Id>.png`。没图之前卡片上只有名字和消耗，不画字顶替。

**sheet2 · 控制**：混乱（hunluan）、封策（fengce）、疑兵（yibing）、离间（lijian）
1. 混乱：徽章里一个打着旋的灰白色漩涡，漩涡里飘着几颗晕乎乎的小星星，边缘带一点淡黄色的眩晕线条。
2. 封策：徽章里一卷竹简被一道朱红色封条斜着封死，封条上盖着一个朱砂方印（只画印泥团，不写字），竹简周围几道锁链。
3. 疑兵：徽章里三面插在土坡上的旗子，旗面残破，旗后面只有几个空荡荡的草人影子，远处一缕黄尘。
4. 离间：徽章里两柄交叉的短剑，剑尖相对，中间夹着一封撕开一半的帛书，帛书边缘烧焦。

**sheet3 · 控制 / 防御**：刺客（cike）、安民（anmin）、水幕（shuimu）、坚守（jianshou）
1. 刺客：徽章里一把寒光闪闪的匕首，刀身映出一轮弯月，匕首后面一片黑色斗篷的轮廓，只露一点。
2. 安民：徽章里一只手掌托着一盏温暖的灯，灯火周围散开几圈柔和的淡金色光环，光环里飘着几片青绿色叶子。
3. 水幕：徽章里一道从上往下落的青蓝色水帘，水帘前面一朵将熄的小火苗冒着白烟，水花四溅。
4. 坚守：徽章里三面大盾并排竖起，盾面是暗红漆加铜钉，盾后露出几杆长枪的枪尖，整体像一堵墙。

**sheet4 · 防御 / 增益**：筑堤（zhudi）、疾风（jifeng）、连击（lianji）、奇袭（qixi）
1. 筑堤：徽章里一道用土袋和木桩垒起的堤坝，堤坝外侧是翻滚的青色浪头，被挡在外面。
2. 疾风：徽章里三道弯曲的白色风线从左往右呼啸，风线里卷着几片叶子，前端一只飞奔的马蹄印。
3. 连击：徽章里两道交叉的白色刀光，呈「X」形，刀光尾部拖着残影，交点处迸出几点火星。
4. 奇袭：徽章里一轮弯月下一支从草丛里探出的长枪，枪头反着月光，草丛里几双发亮的眼睛。

**sheet5 · 攻击**：烈火（liehuo）、业火（yehuo）、火龙（huolong）、山崩（shanbeng）
1. 烈火：徽章里一团比火计更大更猛的橙红火球，火舌向四面卷出，中心发白。
2. 业火：徽章里一根燃着青蓝色火焰的火柱，火柱底部烧出一圈焦黑的地面，火里隐约有几张扭曲的面孔轮廓（不要恐怖，Q 版）。
3. 火龙：徽章里一条由火焰组成的中国龙盘成一圈，龙头在上张口吐火，龙身是流动的橙红火焰。
4. 山崩：徽章里半座褐色山体从上方崩塌下来，大块岩石带着土黄烟尘翻滚，底部压着几面倒下的旗。

**sheet6 · 攻击 / 回复**：水计（shuiji）、落雷（luolei）、伏兵（fubing）、天雷（tianlei）
1. 水计：徽章里一道决堤的洪水从左上角涌向右下，浪头卷着几根木头和一面旗。
2. 落雷：徽章里一道金黄色的闪电从乌云里劈下，打在一块裂开的石头上，四周几点电光。
3. 伏兵：徽章里一片深绿草丛，草丛里探出五六杆枪尖和几顶头盔的轮廓，上方一面小令旗。
4. 天雷：徽章里三道紫白色的闪电从一团翻滚的黑云里同时劈下，云下一片被劈焦的土地。

**sheet7 · 回复**：医疗（yiliao）、神医（shenyi）、激励（jili）、回天（huitian）
1. 医疗：徽章里一卷白色绷带缠着一个打开的药罐，药罐冒出淡绿色的药气，旁边一根银针。
2. 神医：徽章里一个青布药囊，囊口露出几味草药和一柄小刀，药囊上方悬着一颗发着柔光的金色药丸。
3. 激励：徽章里一面迎风的大红战旗，旗下三只举起的拳头，旗周围散着金色的光点。
4. 回天：徽章里一轮初升的红日，从云海里探出一半，云海被染成金色，日轮里有一只展翅的凤凰剪影。
