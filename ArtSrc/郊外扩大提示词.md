# 郊外扩大 · 出图清单

郊外从一屏扩成 2×2 四屏，最后大约 37×24 格。现在这张郊外底图当**左上角**，往右、往下各扩一块，再补右下角。

```
┌──────────────┬──────────────┐
│ 左上（现有）    │ 右上：秋林小道    │
│ 入口、两个水塘   │ 稀疏树林、藏宝    │
│ 右下角空地→小村子 │              │
├──────────────┼──────────────┤
│ 左下：河边草甸    │ 右下：黄巾营寨    │
│ 小河横穿、木桥    │ 河对岸、最远的角   │
└──────────────┴──────────────┘
```

**怎么扩**：我准备好了带边的画布，一边是现有画面的一条（256 像素宽），其余是品红色空白。把画布传给生图工具，让它**把品红色部分画满、已有的那条保持不变并自然延续**，这样接缝能连上。

生图时把 `Assets/LiuBeiRPG/Resources/Map/Art/field_ground.png` 也一起给它当画风参考。

## 1. 右上块 → 生成后存为 `ArtSrc/life/expand/tr.png`

附图：`ArtSrc/life/expand/tr_canvas.png`（左边一条是现有地图的右边）+ `field_ground.png`（画风参考）

```
在这张图上修改：图中品红色（#FF00FF）的部分是空白，请把它画满；左边已有的那一条画面保持原样不动，新画的部分从它自然延续过去，接缝处的草地、岩石、土地颜色和形状要连得上，看不出接缝。
画布尺寸、俯视约 45 度的视角、Q版像素感手绘画风、秋天金黄色草地的色调、光线，都和左边那条以及参考图完全一致。

内容：郊外的秋日草地和稀疏树林的空地。
- 左边那条下方（离底边约 150~300 像素高）是一片黄土空地，从这里接出一条土路，往右边弯弯曲曲穿过草地，一直延伸到画面右上部分，在右上角附近结束于一小片圆形的空地。
- 画面最上边和最右边是一圈灰色山崖岩壁（和左边那条里的山崖同样的画法），把这块地围起来。
- 中间是开阔的金黄色秋草地，散落一些小石头、小花、草丛。
- 不要画树、不要画灌木、不要画房屋、不要画人和动物（树和房子之后单独放上去）。
- 不要阴影、不要文字。
```

## 4. 小村子和木桥 → `ArtSrc/life/village.png`

附图：`zhuoxian_ground.png` 或之前的 `houses.png`（同一画风）

```
游戏地图建筑设定图，Q版像素感手绘，暖色调，俯视约 45 度，和附图里的房子同一画风、同一角度、同样的比例。
画布 2048×1024，纯品红色背景（#FF00FF），无阴影、无地面、无文字、无人。
上下两排，彼此留出明显空隙、绝不重叠，同一排底边对齐：
上排 4 个：
1. 小农舍：茅草屋顶、黄土墙、木门，比刘备家小一点。
2. 另一座小农舍：茅草屋顶，侧面带一个矮矮的柴棚，墙边靠着农具。
3. 草料垛：一大堆圆顶的金黄色干草垛。
4. 水井：石砌井口，上面一个木头井架和辘轳，挂一只木桶。
下排 3 个：
5. 木桥：南北方向（从画面上方通到下方）的一座朴素木板桥，两侧有木栏杆，桥身略微拱起，桥的两端是平的（要能搭在河两岸），整座桥竖着画，长度约是宽度的 2 倍。
6. 一段矮木篱笆（横向，约 5 根木桩宽，用绳子绑着横杆）。
7. 路牌：一根木柱上钉着两块指向左右的木牌（木牌上不要写字）。
物体上不要出现粉色或紫色。
```
