# 启动加载页 生图提示词

微信里打开游戏、下载资源包（约 38MB）时的那一页。进度条和「正在加载资源」的字由微信转换插件自己画在下方，
图里**不要画进度条、不要写字**，只留出位置；进度条颜色在打包脚本里配成和这张图相配的。

生成后放到 `ArtSrc/loading_bg.png`，告诉 Claude 接进微信包（转换插件的启动背景图）。

```
手机竖屏游戏的启动加载背景图，中国古风，手绘水彩质感，和Q版三国角色的画风一致，暖色调。
画布 1080×1920（竖版 9:16）。
内容：东汉末年的乡野黄昏。远处是层叠的青灰色山峦和一座城楼剪影，中景一条土路蜿蜒向远方，路边几株桃树正开着粉色桃花，花瓣随风飘落；近处左侧一面写着"刘"字的旧战旗插在土坡上迎风招展（旗上只有这一个字）。天空是橙金到淡紫的晚霞，薄云。
构图：画面上方 15% 是天空，留给游戏标题；主体景物集中在画面中部（20%~70%）；画面下方 30% 是平缓的土地和草地，颜色偏暗、细节很少、没有任何物体，留给进度条和提示文字压在上面。
不要人物，除旗上的"刘"字外不要任何文字、标志、水印、边框，不要画进度条或按钮。
颜色柔和、明暗对比适中，下方区域整体偏暗，让白色和金色的字压上去清楚可读。
```

可选：做一版 1920×1080 横版的话，同样的内容和要求，只把构图改成「左右展开，下方 30% 留空」。
